# 如何初始化服务器

1. **解析命令行参数：** 在 `cmd/server/main.go:56-82` 中定义并解析各种登录标志和配置选项。

2. **加载环境变量：** 从 `.env` 文件加载环境变量（如果存在），设置存储后端配置 (`cmd/server/main.go:146-151`)。

3. **确定配置源：** 根据环境变量选择配置后端（Postgres、Git、对象存储或本地文件） (`cmd/server/main.go:164-212`)。

4. **加载配置文件：** 使用选定的后端加载配置，处理云部署模式的特殊情况 (`cmd/server/main.go:221-380`)。

5. **构建服务实例：** 使用 Builder 模式组装所有依赖项，创建准备运行的服务 (`sdk/cliproxy/builder.go:155-218`)。

6. **验证完成：** 检查服务是否成功启动，监听配置的端口，准备处理请求。
